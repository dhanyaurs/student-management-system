# Student Management System

A role-based digital platform designed to streamline and automate academic administrative tasks. This web application provides a secure environment where only authorized administrators can manage student records, courses, enrollments, and academic reporting.

## Features
- Secure Admin Access: Restricted role-based authentication ensuring only administrators can access system functionalities.
- Student Management: Features to add new student profiles and view comprehensive student directories.
- Course Administration: Tools to create new academic courses and monitor existing course listings.
- Academic Enrollment: Ability to seamlessly enroll specific students into their designated courses.
- Reporting Engine: Built-in functionality to generate administrative and academic reports instantly.

## Built With
- Python: Core programming language handling the backend server routing.
- Flask: Micro web framework used to manage server requests and application logic.
- MySQL: Relational database management system used to safely store and link student, course, and enrollment data.
- HTML: Markup language used to structure the web forms, tables, and dashboard layouts.
- CSS: Styling language used to design and format the administrative interface.
